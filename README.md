# AI & ML Student Toolkit

A Python project for managing student marks, analyzing academic performance, and visualizing results.

## Features

- Add student records and validate marks.
- Save and load student data using CSV files.
- Display students ranked by marks.
- Calculate the class average and identify the topper.
- Generate student performance charts using Matplotlib.
- Include automated tests using pytest.

## Technologies Used

- Python
- CSV file handling
- Matplotlib
- pytest
- Git and GitHub

## How to Run

Install Matplotlib:

```bash
python -m pip install matplotlib pytest
```

Run the student toolkit:

```bash
python student_toolkit.py
```

Generate a performance chart:

```bash
python visualize.py
```

Run automated tests:

```bash
python -m pytest -v
```
